# Турнир Unmatched — сайт

Статичный сайт (HTML/CSS/JS, без сборки и бэкенда). Все данные о турнире правятся руками в одном файле.

## Как обновлять данные

Всё редактирование — в [js/data.js](js/data.js):

- `characters` — словарь персонажей (`slug: { name, image }`).
- `players` — словарь игроков (`slug: { name }`).
- `matches` — все 31 матч сетки (16 игр в 1/16, 8 в 1/8, 4 в 1/4, 2 в 1/2, финал). Связи между раундами (`nextMatchId`/`nextMatchSlot`) уже прописаны и трогать их не нужно.

Как заполнять по ходу турнира — подробно расписано комментариями прямо в начале `js/data.js`. Коротко:

1. Пара определилась → вписать `slotA`/`slotB` (player + character), `status: "scheduled"`, при желании `scheduledDate`.
2. Матч сыгран → `status: "completed"`, `winner: "A" | "B"`, заполнить `stats`.
3. Победителя нужно вручную вписать в `slotA`/`slotB` следующего матча (id из `nextMatchId`, слот из `nextMatchSlot`) — автоматического переноса нет, это осознанно, чтобы не плодить скрытую логику.

После правки файла просто открываете `index.html` — изменения сразу видны.

## Картинки и шрифт

- `assets/fonts/bebasneuecyrillic.ttf` — шрифт уже подключён.
- `assets/characters/<slug>.jpg` — портрет персонажа (путь задаётся в `characters` в data.js). Пока файла нет — на сайте автоматически показывается плейсхолдер с первой буквой имени, вёрстка не ломается.
- `assets/cardbacks/` — рубашки колод, для будущего использования (например, как фон/декор).

Просто кладите файлы с нужными именами в соответствующие папки — ничего больше делать не нужно.

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub и запушить в него содержимое этой папки.
2. В репозитории: Settings → Pages → Source → Deploy from a branch → выбрать `main` и `/ (root)`.
3. Через минуту-две сайт будет доступен по адресу вида `https://<username>.github.io/<repo>/`.

Дальше любое обновление — это просто `git add`, `git commit`, `git push`: сборка не требуется, GitHub Pages отдаёт статические файлы как есть.
